I build production automations that connect AI models to real business systems —
CRMs, messaging platforms, spreadsheets and vector databases. Most of my work is
in **n8n**: multi-step agent workflows that run against live data, handle real
customer traffic, and have to stay reliable when an upstream API fails.

I care about the parts that are easy to skip: authentication on public webhooks,
retry and error paths, rate limits, and what happens when two executions touch
the same row at the same time.

## Featured work

### [n8n-workflows](https://github.com/engmohamedy100-byte/n8n-workflows)

Eleven production automations — **417 nodes** across AI customer service, sales
pipeline management, appointment scheduling, proposal generation, recruitment,
job search, competitor monitoring and financial alerting. Every workflow is
documented with its data flow, setup steps, required credentials, and an honest
list of its known issues.

| Project | Scale | What it does |
|---|---|---|
| End-to-End Sales Pipeline | 109 nodes, 9 triggers | Full sales lifecycle on Notion, lead capture through onboarding |
| AI Customer Service & Sales | 101 nodes | Arabic WhatsApp agent with RAG retrieval over Supabase |
| Job Application Pipeline | 34 nodes | Applicant intake, AI CV scoring, scheduled cleanup |
| Tadawul Disclosure Monitor | 24 nodes | Saudi Exchange disclosure alerts with LLM analysis |

The repo also ships the tooling I used to publish it safely: a credential
scanner that catches secrets embedded in URL paths — not just headers — and a
workflow analyzer that reports triggers, outbound endpoints and error-handling
coverage.
